## How to use this vault

- New day: create a note in `Journal/` from [[Templates/Journal]].
- New compiler pain: create a note in `Mistakes/` from [[Templates/Mistake]]; the recurring ones are what to drill.
- Status values: `not-started`, `in-progress`, `done`. Confidence: 0 untouched, 1 lost, 3 can do with docs open, 5 can teach it.
